# Video call app

## Commands to start the App
### 
    - npm i
    - npm run dev


## How to use (locally)
### 
    - Enter name and hit "create"
    - Do the same on other device
    - Then click on the call button on the right side of the username in the left sidebar on the '/' page.


## How to use (using Ngrok)
### 
    - Open browser -> go to [NGROK](https://ngrok.com)
    - Log In or Sign Up there
    - Run: npm install -g ngrok
    - Then run: ngrok http 3000
    - You will get a 'https' link that link you can share with others.
